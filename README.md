# PRODIGY_DS_04 - Social Media Sentiment Analysis

## 📌 About the Project

This project is completed as part of the **Prodigy InfoTech Data Science Internship – Task 04**.

The goal of this project is to analyze and visualize sentiment patterns in social media data to understand public opinion and attitudes towards different topics and brands.

---

## 🎯 Objective

The main objectives of this project are:

- Analyze social media tweets
- Identify different sentiment categories
- Understand public opinion
- Find the most discussed entities
- Visualize sentiment patterns
- Compare sentiments across different entities

---

## 📊 Dataset

The dataset used in this project is a Twitter sentiment analysis dataset.

It contains the following columns:

| Column | Description |
|---|---|
| ID | Unique identification number |
| Entity | Brand or topic mentioned |
| Sentiment | Sentiment of the tweet |
| Tweet | Text of the tweet |

### Sentiment Categories

- 🟢 Positive
- 🔴 Negative
- 🟡 Neutral
- ⚪ Irrelevant

---

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 🔍 Project Workflow

### 1. Data Loading
The Twitter dataset is loaded using Pandas.

### 2. Data Cleaning
Missing values are checked and removed.

### 3. Sentiment Analysis
Tweets are analyzed according to their sentiment categories.

### 4. Entity Analysis
The most frequently discussed entities are identified.

### 5. Data Visualization
Different charts are created to understand the sentiment patterns.

### 6. Sentiment Comparison
Sentiments are compared across different entities.

---

## 📈 Visualizations

The project includes:

### 1. Sentiment Distribution
A bar chart showing the number of tweets for each sentiment.

### 2. Sentiment Percentage
A pie chart showing the percentage of Positive, Negative, Neutral, and Irrelevant tweets.

### 3. Top 10 Most Discussed Entities
A bar chart showing the entities with the highest number of tweets.

### 4. Sentiment by Entity
A chart comparing sentiment categories across different entities.

### 5. Sentiment Heatmap
A heatmap showing sentiment distribution across the top entities.

---

## 💡 Key Insights

The analysis helps us understand:

- Which sentiment is most common
- Which entities are discussed the most
- How sentiment differs between entities
- Overall public opinion toward different topics and brands

---

## Conclusion

This project demonstrates how Python can be used to analyze social media sentiment.

The analysis identifies Positive, Negative, Neutral, and Irrelevant tweets and visualizes their distribution. Entity-wise analysis also helps understand how public sentiment varies across different brands and topics.

Overall, sentiment analysis provides useful insights into public opinion and social media trends.
